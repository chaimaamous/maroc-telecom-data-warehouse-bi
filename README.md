# Maroc Telecom — Data Warehouse & Business Intelligence

## Project Overview
Academic Business Intelligence project focused on designing a data warehouse and integrating telecom data for reporting and analysis.

## Technologies Used
- **MySQL / SQL:** Relational database and data warehouse
- **Apache Hop:** ETL pipelines and workflow orchestration
- **Power BI:** Interactive dashboards and data visualization

## Data Architecture
1. **Source Database (OLTP):** Telecom operational data
2. **ETL:** Extract, transform and load data using Apache Hop
3. **Data Warehouse (OLAP):** Dimension and fact tables
4. **Power BI:** Business reporting and KPI visualization

## Repository Structure
- `sql/` — SQL scripts
- `etl/` — Apache Hop pipelines and workflow
- `powerbi/` — Power BI dashboard
- `docs/` — Project documentation

## Key Skills Demonstrated
- Data Warehouse Design
- ETL Development
- SQL and Data Modeling
- Business Intelligence
- Data Visualization

Academic group project.
